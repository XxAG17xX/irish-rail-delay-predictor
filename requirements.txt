# Everything needed to run and train locally: the poller, the API, the trainer and the
# analysis scripts. Nothing in here is a development tool -- those live in
# requirements-dev.txt, which installs this file too.
#
# The split exists because cfn-lint dragged in sympy, mpmath, networkx and regex, and a
# reader could not tell what the project actually imports from what a linter needed. Same
# reasoning as requirements-lambda.txt and requirements-api.txt, which are narrower still:
# neither of those ships boto3 (the Lambda runtime provides it) and neither ships uvicorn
# (Mangum replaces it in Lambda).
#
# Pins are exact. numpy, scipy and lightgbm decide the numbers a retrain produces, so an
# unpinned upgrade is a silent change to the model.

# where Mangum is the adapter instead.
